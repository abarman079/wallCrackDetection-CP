# Licensing and citation decisions (not automatically granted)

This repository currently has **no explicit software license**. That means public visibility alone does not grant permission to copy, modify or redistribute the code. The owner should select a suitable license **only after confirming rights in all inherited and third-party code** and any research/supervisor or institutional requirements.

Recommended actions before a formal release:

1. Identify original versus incorporated code, including imported model adapters and any third-party source, with exact upstream license versions.
2. Verify redistribution rights for model code and **separately** for source datasets, masks and figures. Dataset rights do not automatically follow a software license.
3. Choose an appropriate license with the research owner/institution. Add `LICENSE` and a complete `CITATION.cff` with confirmed author identities and preferred citation **after** review.
4. Cite the v3.3 blueprint, source literature, original dataset publications and any released paper with accurate DOI metadata. Do not invent DOIs or author details.

Until those actions happen, see the repository for review and reproduction guidance, not an implied license to reuse restricted content.
