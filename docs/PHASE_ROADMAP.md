# Eight-phase roadmap — locked scientific scope

1. **Phase-01:** design, literature, reproducibility, protocol and statistical correction. Technical evidence archived.
2. **Phase-02:** inventory, provenance, source-safe split, mask semantics and independent-unit eligibility. Technical evidence archived; certification gates blocked.
3. **Phase-03:** original model roster, common-protocol baselines, seeds and ensemble. Official notebook retained; separate real development-only baselines in three sub-notebooks are running.
4. **Phase-04:** structural/branch metrics and predictions from frozen development checkpoint(s); test topology primitives synthetically and label empirical outputs development-only.
5. **Phase-05:** prediction-only structural confidence and uncertainty scores on permitted development data; do not optimize using reserved calibration/test labels.
6. **Phase-06:** exact two-risk algorithm, finite-family correction, selective prediction and entropy competitor; synthetic algorithm verification is independent of unavailable genuine calibration.
7. **Phase-07:** shift, negatives, corruption and external robustness; do not open reserved source-test/calibration observations until eligible.
8. **Phase-08:** credible figures/tables, reproducibility packages, documented limitations and thesis/paper narrative. Use only genuinely performed runs.

**Organization:** Eight *official* numbered phase folders. Within `Notebook 3/development/v4/`, three per-architecture runner notebooks are supplemental execution tools, not extra official scientific phases. Follow one official notebook per later phase.
