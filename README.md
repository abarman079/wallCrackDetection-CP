# CrackSAFE-CP

Component- and Topology-Aware Risk-Controlling Prediction
for Selective Structural Crack Segmentation under Domain Shift.

## Research objective

MSc research project investigating structural crack segmentation,
topology-aware uncertainty, selective prediction, statistical
risk control, and robustness under domain shift.

## Implementation

The project follows the v3.3 research blueprint and contains
eight sequential Kaggle notebooks.

## Project progress

- Phase 01: Legacy, literature and design locks — FULL inventory completed.
- Phase 02: Data integrity, leakage, annotation and splitting — next.
- Phases 03–08: Planned.

full Kaggle output bundles are stored outside GitHub.

subsequent phase.
